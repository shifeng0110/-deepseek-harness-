# dsh-livewall · DeepSeek Harness 动态壁纸插件

在 DeepSeek Harness Web GUI 背后铺一层动态壁纸(程序生成动效 / 本地或网络视频 / 图片),不改变任何现有组件与功能;所有配置都在 **设置 → 动态壁纸** 整页里。

> 本目录是从你的工作副本发布到仓库的**脱敏版**:不含任何本机路径 / 用户名 / 密钥。
> 默认素材目录在运行时按 `$DSH_LIVEWALL_ASSET_DIR > $DSH_HOME\bg-assets > <用户目录>\.dsh\bg-assets` 解析,可在设置页改成任意绝对路径。

## 文件与装配位置(以你的 profile 为准)

| 位置 | 说明 |
|---|---|
| 本仓库 `livewall/` | 插件源码(host 半 `lib/index.js` + 浏览器半 `lib/client.js` + `package.json` + `sync.js`) |
| `<profile>\node_modules\dsh-livewall\` | 装配到 profile 的同步副本(改源码后重拷一遍) |
| `<profile>\cordis.patch.yml` | 加一行 `livewall` 装配(见下) |
| 素材目录 | 默认按上文解析;设置页可改成任意绝对路径 |
| 设置文件 | Harness 的 settings.yaml(自动写入 `livewall` 命名空间) |

示例(web profile 常见位置,用户名按你的替换):
`C:\Users\<你的用户名>\.dsh\profiles\web\node_modules\dsh-livewall\`

## 安装

1. 把本 `livewall/` 目录复制为 `<profile>\node_modules\dsh-livewall\`(如 web profile:`…\.dsh\profiles\web\node_modules\dsh-livewall\`);
2. 在 `<profile>\cordis.patch.yml` 加入一行装配(若无该文件就创建,结构仿照 dsh-base 的 patch):

```yaml
- insert:
    - id: livewall
      name: 'dsh-livewall'
      config:
        assetDir: 'C:\Users\<你的用户名>\.dsh\bg-assets'
```

3. 重启 dsh web,浏览器 **Ctrl+F5** 硬刷新;
4. 打开 GUI → 左下设置 → **动态壁纸**。

## 使用

1. 打开"启用动态壁纸",点选预设(点选即应用并保存):
   - **星尘粒子 / 极光渐变 / 柔光斑**:程序生成,无需素材;
   - **视频壁纸 / 图片壁纸**:素材目录列表里点文件名直接应用;或用上传按钮选本地文件;或在 URL 框贴网络直链后点"应用 URL";
2. 两个滑杆(0–1):**壁纸不透明度**(整层强弱)、**面板不透明度(0=全透,1=实心)**(0 最清晰、文字浮于壁纸;0.3–0.5 玻璃感兼顾可读;1 恢复不透明界面);
3. 视频壁纸可勾"启用壁纸声音"(浏览器自动播放策略:勾选后若无声,点击页面任意处一次);
4. 明/暗主题自动换配色;切走标签页自动暂停省电。

## 素材格式

- 视频:**H.264 的 .mp4 / VP9 的 .webm**(HEVC/H.265 多数浏览器不支持;转码示例:`ffmpeg -i in.mov -c:v libx264 -pix_fmt yuv420p out.mp4`);
- 图片:png / jpg / jpeg / webp / gif / apng / avif / svg / bmp;
- 上传上限 512MB;视频走 HTTP Range,循环流畅。

## 修改源码后同步到 profile

```bat
cd livewall
node sync.js
```

或手动 `copy /Y` 三个文件到 `<profile>\node_modules\dsh-livewall\`。改 host 半(`lib/index.js`)需重启 dsh web;只改浏览器半(`lib/client.js`)则 **Ctrl+F5** 即可。

## 回滚/卸载

1. 删除 `<profile>\cordis.patch.yml` 里的 `livewall` 装配块;
2. 删除 `<profile>\node_modules\dsh-livewall\` 目录;
3. 重启 dsh web(界面恢复原不透明样式,已保存配置仍在 settings 里)。
