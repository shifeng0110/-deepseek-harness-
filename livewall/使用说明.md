# dsh-livewall · DeepSeek Harness 动态壁纸插件

在 Harness Web GUI 背后铺一层动态壁纸(程序生成动效 / 本地或网络视频 / 图片),不改变任何现有组件与功能;所有配置都在 **设置 → 动态壁纸** 整页里。

## 使用

1. 安装/升级/改 patch 后:**重启 dsh web**(关掉 Harness 窗口 → 重跑 `启动Harness.cmd`),再 **Ctrl+F5** 硬刷新浏览器;
2. 打开 GUI → 左下设置 → **动态壁纸**;
3. 打开"启用动态壁纸",点选预设(直接点选即应用并保存):
   - **星尘粒子 / 极光渐变 / 柔光斑**:程序生成,无需素材,可调速度 / 密度 / 浓度;
   - **视频壁纸 / 图片壁纸**:在"素材目录"列表里点文件名直接应用;或用上传按钮选本地文件;或在 URL 输入框贴网络直链后点"应用 URL";
4. 两个透明度滑杆(0–1):
   - **壁纸不透明度**:壁纸整层强弱(0=不显示);
   - **面板不透明度(0=全透,1=实心)**:控制现有 UI 面板多透明。0 时壁纸最清晰、界面文字直接浮于壁纸上;0.3–0.5 是"玻璃感 + 文字可读"的折中;1 恢复成完全不透明界面(壁纸仅可见于缝隙,基本等同关闭效果);
5. **视频壁纸声音(可选)**:媒体区勾选"启用壁纸声音"。浏览器自动播放策略要求"先有用户操作才能带声播放",所以勾选后若仍无声,**点击页面任意处一次**即可;无音轨的视频(如部分录屏)天然无声,与插件无关;
6. "素材目录"可改成任意绝对路径,点"保存目录"立即生效(粘贴带引号的路径也会自动清洗);
7. 明/暗主题切换时壁纸自动换配色;切换页面标签页(隐藏)时自动暂停省电。

## 素材格式

- 视频:**H.264 的 .mp4 / VP9 的 .webm** 直接播;HEVC/H.265 多数浏览器不支持,需转码(ffmpeg 示例:`ffmpeg -i in.mov -c:v libx264 -pix_fmt yuv420p out.mp4`);
- 图片:png / jpg / jpeg / webp / gif / apng / avif / svg / bmp;
- 上传上限 512MB;视频走 HTTP Range 播放,循环流畅。

## 修改源码后同步

```bat
node F:\dpharnesstest\livewall\sync.js
```

等价于三条 `copy /Y`(index.js / client.js / package.json → profile 副本)。改 **host 半**(index.js)需重启 dsh web;只改 **client 半**(client.js)时**只硬刷新浏览器(Ctrl+F5)即可**,无需重启(服务器按请求读盘)。

## 常见问题

- **素材目录列表报错 / 素材 404**:检查设置里"素材目录"值没有多余引号或结尾反斜杠(现在保存时会自动清洗,老数据仍异常就重存一次);
- **为什么看起来像蒙了一层雾**:面板不透明度偏高。想壁纸清晰就把"面板不透明度"调低(0.3 以下),或"壁纸不透明度"拉满;
- **视频不动 / 黑屏**:确认是 H.264 mp4 或 VP9 webm(HEVC 浏览器不支持),换浏览器试(推荐 Chrome/Edge);
- **改了设置没生效**:等 1 秒(写盘),若仍不对就 Ctrl+F5;host 侧改动必须重启 dsh web。
