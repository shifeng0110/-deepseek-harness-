# 鲸鱼娘 · DeepSeek 状态浮窗（whale 文件夹）

浮在 DeepSeek Harness GUI（http://127.0.0.1:3080）上的鲸鱼娘组件：头顶对话框显示
**峰谷 / 真实余额 / 自定义台词**，点鲸鱼头循环切换，按住可拖动。

> 已支持 **真正嵌入 GUI 本体**：dsh-web-frontend 的 dist/index.html 被注入一行
> `<script src="/whale-widget.js">`（带 `<!-- dsh-whale-embed -->` 标记、可逆），
> 每次打开/刷新 GUI 页面鲸鱼娘都自动出现，无需手动注入。
> dsh 升级或重装 npm 包后需重跑一次：`node patch-gui.js patch`（移除用 unpatch）。

## 目录内容

| 文件 | 作用 |
|---|---|
| `whale-girl.png` | **你的鲸鱼娘图片**，透明 PNG 最佳，直接放这里即被加载（缺失时显示 🐳 兜底） |
| `config.example.json` | 配置样例：官方闲时段表 `schedule`、台词 `lines`、余额刷新间隔、`apiKey`(需自行填写)。**首次使用先复制为 `config.json` 再填 Key** |
| `proxy.js` | 本地代理（127.0.0.1:8790）：转发官方余额接口、提供图片与配置 |
| `widget.js` | 注入组件源码（唯一代码源） |
| `patch-gui.js` | **嵌入/移除 GUI 本体**：`node patch-gui.js patch` / `unpatch` / `status` |
| `whale.user.js` / `inject-demo.js` | Tampermonkey 版 / 控制台粘贴版（备用；嵌入后一般用不到） |
| `启动鲸鱼娘.cmd` | 双击启动本地代理 |
| `build-dist.js` | 修改 widget.js 后执行 `node build-dist.js` 重新生成上两个分发文件 |
| `test-schedule.js` | 峰谷逻辑单测 |

## 使用（嵌入模式，推荐）

1. **放图 + 填 Key**：图片存为 `whale-girl.png`；把 `config.example.json` 复制一份为 `config.json`，在 `config.json` 里填 `sk-` Key(密钥请勿提交到仓库)。
2. **启动代理**：双击 `启动鲸鱼娘.cmd`（黑窗口保持开着）。
3. **刷新 GUI 页面**（F5）：右下角即出现鲸鱼娘，之后每次打开都在。

首次嵌入/或 dsh 升级后：在 whale 目录跑一次 `node patch-gui.js patch` 再刷新即可。

## 峰谷判定（默认，2026-09-03 官方定价页核对）

> 高峰 = **北京时间 周一至周五 9:00–12:00、14:00–18:00**；其余时间（含周末、
> 午休、夜间）= 空闲时段，价格为高峰的**一半**。
> 来源：https://api-docs.deepseek.com/zh-cn/quick_start/pricing

官方规则变更时，直接改 `config.json` 的 `schedule` 即可，无需改代码。

## 交互

- **点鲸鱼图标**循环切换 峰谷 → 余额 → 台词；点气泡空白处不切换；
- 台词模式下用气泡内 **‹ ›** 按钮逐句切换（手动切换后自动轮播会暂停一段时间）；
- 按住图标/气泡拖动可移动，位置自动记忆（刷新后仍在）；
- 文本变长时**气泡向上扩展、图标位置不动**；
- 气泡右上「−」收起为小圆点，点圆点展开。
- 改了界面代码 `widget.js` 后：执行 `node build-dist.js && node patch-gui.js patch`，然后 **Ctrl+F5 硬刷新** GUI 页面（/whale-widget.js 可能被浏览器缓存）。

## 常见问题

- **双击 cmd 报 `'1' 不是内部或外部命令` 之类乱码**：已修复为纯 ASCII 脚本，重新双击即可（旧版是 UTF-8 中文在 GBK 命令行下被误读导致）。
- **提示端口 8790 已被占用 / EADDRINUSE**：说明已有一个代理实例在运行，直接用即可；或关掉多余的黑窗口再双击。可先开 http://127.0.0.1:8790/ 查看状态。
- **余额一直失败/显示未启动**：确认 `启动鲸鱼娘.cmd` 已运行、`config.json` 的 `apiKey` 已填。
- **显示 🐳 兜底图**：`whale-girl.png` 不存在或路径没对上。
- **改了台词/时段不生效**：改的是 `config.json`（不是代码）；台词在代理开着时下次进入台词模式即读取。
- **改了 widget.js 后页面还是旧的**：`node patch-gui.js patch` 已刷新嵌入副本时，浏览器可能缓存了 `/whale-widget.js`，请 **Ctrl+F5 硬刷新**。
